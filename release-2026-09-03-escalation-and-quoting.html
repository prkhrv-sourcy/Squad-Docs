S-Quad · Release

Escalation handover and quoting fixes

3 September 2026 · 27 changes · 9 database updates. The agent can now ask a person for help, and eleven quoting problems from August are fixed.

← All release notes

The agent can ask for help

New. It was the main piece of work.

Issue

The agent got stuck and had no way to ask. Growth typed free text that the agent could not act on.

Fix

The agent lists what a person can actually do. Growth picks one. The agent tries it and reports back.

Off in production. Nothing writes to the new records there yet, so the panel will not appear. Turning it on is a separate job — see Rollout.

Quoting

Eleven items Growth reported between 10 and 31 August.

Issue

FOB quotations could not be published.

Fix

Two rules disagreed about whether carton sizes were needed. Now there is one rule, and FOB does not need them.

Issue

The Products tab blocked options for missing carton sizes.

Fix

That screen runs before anyone picks FOB or DDP, so it cannot know if a carton will ever be priced. It no longer asks.

Issue

Air or sea was asked in several places, with different numbers.

Fix

One question, two prices, then one summary: freight, last mile, customs, total, and the weight it is charged on. The number shown is the number used.

Issue

Growth could not say whether they had measured a product or a carton.

Fix

A choice on the line, and one place that reads it. Before, four parts of the system guessed separately — including the one that publishes, which could publish different numbers than the screen showed.

Issue

The quotation stage was asked after the items it applies to were chosen.

Fix

Moved to the Products tab, next to the list it describes.

Issue

MOQ showed the ordered quantity.

Fix

They are two numbers again. The supplier's minimum was being overwritten by the chosen price break.

Issue

The customer document ignored choices Growth had made.

Fix

Main image, customer-facing name, billing company, exchange rate and its date all print what was chosen. They were honoured in the preview and dropped at publish.

Issue

An older version of a quotation could not be brought back.

Fix

It can, and it shows every field it will change — old value to new — before anything is written.

Issue

Customers and contacts could not be created or corrected in Squad.

Fix

They can. "New company" now appears below the search results, not above them, so nobody creates a duplicate of the company they just searched for.

Issue

Saving a validated option failed with an error about the packing field.

Fix

The screen wrote a field the server did not accept, so the whole save was rejected. Both sides agree now, and a test fails if they drift apart again.

Issue

Smaller things: publishing mid-run gave no warning; searching an SR number did not put it first; the "agents unreachable" message had no retry; options quoted at different quantities looked comparable; long option lists could not be filtered.

Fix

All five done.

Found while building

Problems that would not have been visible until they bit.

Issue

The same job could be done twice — contacting the same suppliers twice.

Fix

The agent held a job for one hour, but this job waits on suppliers for longer. It now says "still going" and keeps its hold.

Issue

A customer requirement could be loosened without anyone choosing it.

Fix

The list of requirements came up with the first one already selected. Nothing is submitted now until a choice is made.

Issue

A note typed for one choice was submitted under another, unseen.

Fix

The note clears when the choice changes.

Issue

Some records could never have been saved — the save would simply fail.

Fix

There was a limit on how many notes were kept but not on their size. There is now a size limit too.

Issue

Safety checks were being skipped without anyone noticing.

Fix

Comparisons against a missing value quietly passed instead of failing. They are written so a missing value is refused.

Rollout

The database updates run first. If one fails, the running app is left alone.

  1. Deploy. The nine database updates run first, and stop the deploy if any fails.
  2. Check the request list still flags escalated requests. It reads both the old and new records during the move.
  3. Check a quotation can be published on FOB, and an older version restored.

Also in this release

Issue

Squad requests were identified by a bot tag.

Fix

They carry the operator's employee id and lane tags instead.
